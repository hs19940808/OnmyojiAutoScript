# 启动保留本地修改

2026-11-12 检查结果：OASX程序内包含 `python -m deploy.installer` 启动命令，旧GUI启动脚本也调用该安装器。安装器调用 `deploy/git.py` 的 `git_install()`。

原更新器有两处强制重置：关闭保留本地修改时直接重置；开启保留选项但stash失败时仍回退到强制重置。因此仅打开 `KeepLocalChanges` 不能覆盖所有失败路径。没有找到能证明此前每次启动都实际执行了重置的日志。

已处理：

- 当前 `config/deploy.yaml`、配置默认值和模板均关闭启动自动更新（`AutoUpdate: false`）。
- 配置保留 `KeepLocalChanges: true`。
- 删除所有强制重置和自动stash分支，即使旧启动器传入不保留修改的选项，也不会清除工作区。
- Git初始化失败不再删除现有Git元数据，更新时不再强行删除Git锁文件。
- 启动更新与手动更新均只允许 `pull --ff-only`。遇到重叠的本地修改或非快进历史时失败退出，保留原文件。

验证：

- `toolkit/python.exe -m unittest discover -s tests -p test_startup_preserve.py -v`：6项测试通过。
- 使用本机临时Git仓库测试，未访问远程网络：上游修改同一文件时，两种旧保留选项均保护本地文件、HEAD及空stash状态；上游修改其他文件时，更新成功且定制文件不变。
- 使用实际当前配置调用启动Git阶段，确认其跳过更新、执行0条Git命令。没有重启OASX窗口，也没有运行会结束其他进程的完整安装器。
- 比较23个百鬼源码及测试文件的SHA-256，全部保持不变。详见 `verification.json`。

本目录的 `local-fixes-backup.zip` 包含31个相关源码、测试及配置文件；`all-changes.patch` 保存当前已跟踪文件的完整差异。源码尚未提交。
